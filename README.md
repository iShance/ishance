### About me

I work across the whole delivery cycle, and I like owning a product end to end:

- **Interfaces:** responsive, accessible, quick to load, in light and dark.
- **Backends:** APIs and services built to stay up, with tests that run before every deploy.
- **Data:** schemas, migrations and queries that stay correct under load.
- **Shipping:** CI, edge deploys and a VPS I run myself.
